# 定价方案 v1（dph-emotion-arc 语C 资产轨）

> 编制：2026-10-01。定价依据分级：A 级 = 调研报告已核验证据（带来源）；B 级 = 基于 A 级的推断建议；外部市场扫描（淘宝/小红书/Fiverr 实价）本轮因网络不可达未能完成，列为**显式缺口**，恢复后重扫校准。

## 一、依据（A 级证据，源自调研报告）

| 证据 | 含义 | 来源 |
|---|---|---|
| 付费点排序：记忆不丢失 > 角色卡牌/抽卡/买断 > 剧情 > 通用闲聊 | 「叙事资产」才是付费标的，不是对话服务 | 报告 §02（用户一手体感 + 创始人访谈） |
| 猫箱 AI 角色卡可充值抽卡、向创作者购买、已出现角色被「买断」 | 角色资产有独立交易市场与买断形态 | 报告 §02（人人都是产品经理/白鲸出海） |
| LoveyDovey 按句计费 + 最高 $69.99/月，续订率约九成 | 高 ARPPU 来自「乙游化 + 强内容」，价格锚点高 | 报告 §02（白鲸出海/36氪） |
| 语擦师经济：年入百万案例、时代峰峻官方招聘角色互动人员 | 定制服务付费心智已被验证 | 报告 §08 |
| 「正文产量位已被 API 打到 1 集 1 块钱」 | 纯字数外包是死路，卖结构/人设/弧线才有溢价 | 报告 §08 |
| 长尾残酷：仅 10% 应用贡献 89% 收入 | 不求规模，求高单价小客群 | 报告 §02（QuestMobile） |

## 二、产品线（对应交付物）

1. **成品人设包**（标准化 SKU）：角色卡 V3 全字段 + 口癖表 + 情绪弧线节拍表 + 3 场景包 + 双生态说明（= samples/persona-pack-suwanqing 的完整版）
2. **定制人设包**（To C 服务）：按客户设定创作，含 2 轮试聊调优
3. **B 端小单**（To B，半单人）：游戏/影游团队的角色情绪状态机 + 弧线节拍表（报告 MVP-3 定位）

## 三、建议价位（B 级推断，待市场扫描校准）

| SKU | 建议价 | 定价逻辑 |
|---|---|---|
| 成品单卡（轻量） | ¥9.9–19.9 | 抽卡/买断锚点（猫箱）之下、奶茶价带，冲动消费无阻力 |
| 成品合集（3 角色） | ¥29–49 | 单卡价 ×3 打 7-8 折，抬客单价 |
| 定制人设包（含 2 轮调优） | ¥199–499 | 对标语擦师定制服务心智（年入百万行业），工时 4-8h 的合理回报 |
| 定制·复杂（多角色/世界书/长剧情） | ¥800–2,000 | 乙游化内容价带（LoveyDovey $69.99/月锚点说明高内容付费存在） |
| B 端情绪状态机 + 节拍表 | ¥3,000–8,000/单 | Inworld Developer $300/月锚点（报告 MVP-3）；内容层无公开市场，空白与风险并存，报价试探性 |

**纪律**：成品包走「买断式交付」（一次付费文件归客户），不承诺更新维护；定制单收 50% 定金、交付后 1 轮免费修改；所有交易声明「创作辅助，非心理服务」。

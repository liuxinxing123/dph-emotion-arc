# 苏晚晴 人设包 · 使用说明

**这是「付费级人设包」的样品结构**——展示一套完整交付物长什么样。本包 MIT 开源，免费使用。

## 包含文件

| 文件 | 用途 |
|---|---|
| 苏晚晴-角色卡-V3.json | 主卡（V3 全字段：人格分层/雷区/示例对话/系统提示词）——直接导入 SillyTavern 或 dph-emotion-arc |
| 口癖表.md | 语言指纹：口头禅/句式/禁止句式——保证跨会话人设一致 |
| 情绪弧线节拍表.md | 7 情绪标签 → 人格化策略映射——与 dph-emotion-arc 状态机联动 |
| 场景包.md | 3 个可直接粘贴的开场 |

## 在 dph-emotion-arc 中使用

1. 让 Agent 执行：`emotion_card_import path='<本目录>/苏晚晴-角色卡-V3.json' personaId='suwanqing'`
2. 之后每次对话，系统上下文自动注入「当前角色卡：苏晚晴 + 人格」，情绪识别同时工作。
3. 想让人格反应更细，把「情绪弧线节拍表」的内容追加进角色卡 `personality` 字段后重新导入。

## 在 SillyTavern 中使用

导入 `苏晚晴-角色卡-V3.json`；把「口癖表」内容放进角色卡的「作者备注/系统提示」；「节拍表」可用于世界书条目（按情绪触发）。
